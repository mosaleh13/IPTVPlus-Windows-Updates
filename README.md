# IPTV Plus für Windows

Hier findest du Installationsdateien und automatische Updates für IPTV Plus.

**[Neueste Version herunterladen](https://github.com/mosaleh13/IPTVPlus-Windows-Updates/releases/latest)**

1. Lade bei der neuesten Version die Datei `IPTVPlus-Setup-...-win-x64.exe` herunter.
2. Schließe IPTV Plus und führe das Setup aus. Playlists, Einstellungen, Verlauf,
   Downloads und Aufnahmen bleiben erhalten.
3. Ab Version 1.2.0 erkennt die App künftige Updates selbst und lädt sie im
   Hintergrund herunter, sobald keine Wiedergabe, Aufnahme oder anderer Download läuft.
4. Mit **Install and restart** wird ein bereitstehendes Update installiert.

Windows 10/11 x64 wird benötigt. .NET und VLC sind enthalten.
Für die Update-Suche in der App brauchst du kein GitHub-Konto.

Version 1.1.0 und älter haben noch keinen Updater. Installiere die neue Version
einmal mit dem Setup; danach funktionieren automatische Downloads.

Das Setup ist derzeit nicht mit einer Windows-Herausgebersignatur versehen.
Die App kontrolliert die signierten Update-Metadaten und die Prüfsumme des Downloads.

Dieses Repository enthält die öffentlichen Pakete und Versionshinweise, keinen
App-Quellcode und keine Zugangsdaten.
